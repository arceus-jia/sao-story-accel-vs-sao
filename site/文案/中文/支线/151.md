# 支线 151

## 场景 0100

千百合：唉……  
千百合：我是不是……该开始感到紧张比较好啊……  
亚丝娜：紧张什么？  
千百合：哇哇！啊，亚丝娜……小姐。  
亚丝娜：呵呵，叫我亚丝娜就好。  
千百合：那就亚丝娜……对、对不起喔，自言自语一些怪话。  
亚丝娜：不会，不过那是什么意思？感到紧张比较好……这说法很奇怪呢？  
千百合：嗯、嗯……跟亚丝娜应该可以讲吧……  
千百合：不、不要对任何人说喔？  
亚丝娜：嗯，当然了。  
千百合：我……其实不久之前在跟小拓交往……  
亚丝娜：嗯。  
千百合：咦，你不意外吗？  
亚丝娜：啊，对啊……隐隐约约感觉到了。看你们的距离感就猜到了。  
千百合：这、这样啊……原来你看出来了……可是我虽然觉得小拓很重要，却也同样很珍惜小春……  
千百合：因为他们两个，都是我重要的童年玩伴……  
千百合：不过来到这里后，周遭的可爱女生又变多了。  
千百合：我也觉得自己跟他们两人间的关系，不上不下的……  
千百合：于是就在想，我是不是太沉溺在童年玩伴的立场了……觉得有点后悔……  
亚丝娜：嗯……所以说我也是千百合的烦恼源之一吗？  
千百合：啊，亚丝娜有桐人了……所以我想应该是没关系……  
亚丝娜：这样啊……呵呵呵。不过啊，千百合感觉是有点太巴着这个立场不放。  
亚丝娜：春雪跟拓武两个人……在我看来都是非常有魅力的喔。  
千百合：咦咦！？哪有，他们都只是小孩子！  
千百合：小春在现实中外观看起来也差不多就是那样，  
千百合：小拓虽然表现得很沉着冷静，但动不动就自暴自弃然后失控……  
亚丝娜：呵呵，但是你连这样子的他们都喜欢，对吧。  
千百合：……！  
千百合：我已经……不知道到底是不是喜欢了。总有种很奇怪的感觉……  
亚丝娜：呵呵，不过我放心了。  
千百合：咦？  
亚丝娜：超频连接者的女孩子们明明年纪都比我小，但都感觉很成熟不是吗？  
亚丝娜：只有千百合……给我符合年龄的感觉，所以才这样说。  
千百合：啊哈哈……这我应该也只能承认了吧。  
亚丝娜：不过可别觉得这种心情很讨厌，要好好珍惜喔。  
千百合：咦……？  
亚丝娜：因为，为喜欢的人烦恼的时候，你会认识自己全新的另一面。  
亚丝娜：你可能会因为和过去的自己落差太大吃上苦头，觉得心里不好受或是很劳神费力。  
亚丝娜：即使如此……恋爱还是很棒的。  
亚丝娜：千百合总有一天，也会感谢自己曾经爱过。  
千百合：亚丝娜……  
千百合：亚丝娜也是……像这样子喜欢着桐人吗？  
亚丝娜：嗯，是啊。  
亚丝娜：桐人真的都一副无所谓的样子，我到底有多烦恼……他应该到现在还是不懂～  
千百合：呵呵。  
亚丝娜：啊啊～！光这么想就觉得有点火大！  
亚丝娜：千百合，我们现在马上去吃点甜食吧！  
千百合：咦咦！？  
亚丝娜：女孩子谈恋爱话题就是要配甜食！这个铁则不管在哪个时代都一样吧？  
千百合：呵呵，确实是这样！好，那就出发去吃甜点啰！  
亚丝娜：喔喔～！
